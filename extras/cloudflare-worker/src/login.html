Anmeldung mit Passkey

Neuer Passkey

In Home Assistant unter Bastion → Alarmanlage → Einstellungen → Cloud-Worker „Passkey koppeln“ wählen und den 8-stelligen Code eingeben.

Wandtablet

Auf einem angemeldeten Gerät unter Sicherheit → Sitzungen „Wandtablet koppeln“ wählen und den Code hier eingeben. Das Tablet bleibt lange angemeldet, darf aber nur anzeigen.

Geschützt durch Cloudflare Access und Passkey.
